# sdd-swe

A Spec Driven Development developed SWE agent for https://learn-ai.devpost.com/

2. I also installed Context7 plugin for fresh library and source code documentations
3. I installed DevPost's SDD hackathon plugin from https://github.com/challengepost/devpost-curriculum
