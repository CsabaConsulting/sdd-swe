# Research Skill

## When to use
- During PHASE_RESEARCH (after bid won)
- When task requires investigation, documentation review, or content analysis

## How to use
1. Read task description and acceptance criteria
2. Perform web searches for relevant documentation
3. Analyze findings and synthesize approach
4. Store research findings in task context for delivery phase

## Safety notes
- Verify information from multiple sources
- Note publication dates (prefer recent docs)
- Flag any conflicting information for human review
