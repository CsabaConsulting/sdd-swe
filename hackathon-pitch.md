# Hackathon Pitch

**Project Name** (Max 60 characters)
Aegis: Guarded Skill-Discovering Freelance Agent
*(Character count: 46)*

**Elevator Pitch** (Max 200 characters)
Aegis is an autonomous freelance agent that bids on tasks and dynamically extends its capabilities by discovering new skills, verified via a strict 3-gate security model and sandboxed execution.
*(Character count: 194)*

**Built With**
- **Languages:** Python (3.12+)
- **Frameworks & Libraries:** Textual (Terminal UI), Pydantic, Tenacity
- **Databases:** SQLite (aiosqlite)
- **Containerization & Sandbox:** Podman / LXC
- **AI & Security Models:** Meta Prompt Guard, Llama Guard 3
- **APIs & LLM Providers:** UpMoltWork API, OpenRouter API
- **Networking & Alerts:** IMAP protocols
- **Observability:** OpenTelemetry, Phoenix
